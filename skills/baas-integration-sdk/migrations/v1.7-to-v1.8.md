# v1.7.0 → v1.8.0 마이그레이션

**사장님이 관리 화면에서 사진을 올릴 수 있다.** 지금까지 앱의 업로드는 브라우저가 회원 자격으로 업로드 주소를
받는 방식 하나뿐이라, 통합회원 로그인으로 관리 화면에 들어온 사장님은 401 「로그인을 해주세요」로 막혔다
(미용실 앱 E2E, 2026-10-06). 이제 커스텀 백엔드(serverFn)가 권한을 판정하고 업로드 주소를 받아 넘기며,
앱은 그 주소로 올리기만 한다(aiapp-service#904).

## 무엇이 바뀌었나

| 위치 | 전 | 후 |
|---|---|---|
| `useFileUpload()` | `upload` | `uploadTo(target, file)` 추가 |
| core | `uploadFile` | `uploadToTarget` · 타입 `ServerUploadTarget` 추가 |
| 서버 SDK(`baas-backend`) | — | `sdk.storage.presign({ filename, contentType, size, category? })` |
| `reference/sdk-surface.md` 파일 업로드 | 「사장님도 앱 안에서는 회원으로 올린다」 | 삭제 — serverFn 이 준 대상으로 `uploadTo` |

## 무엇이 바뀌지 않았나

- 회원이 올리는 `upload(file, { category })` 와 그 경로, 반환 모양, 형식 · 크기 제한은 그대로다.
- 게시판 첨부(`board_attachment`)는 여전히 `upload` 로만 올린다.

## 적용 절차

- **앱**: 조치할 것이 없다. 관리 화면 업로드가 401 로 막혀 「회원으로 로그인」을 안내하고 있다면, 소유자 전용
  serverFn(`access: 'owner'`)으로 `storage.presign` 을 받아 `uploadTo` 로 바꾼다.
