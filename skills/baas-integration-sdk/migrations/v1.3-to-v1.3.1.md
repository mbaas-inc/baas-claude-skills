# v1.3 → v1.3.1 마이그레이션

**SNS 로그인 버튼이 있는 앱은 수정이 필요하다. 이동 경로가 바뀌었고, 복귀 후 화면을 앱이
직접 제공해야 한다 — 화면을 새로 만들어야 하므로 Tier 2.** SNS 를 쓰지 않는 앱은 무영향.

## 무엇이 바뀌었나

### 서버 (aiapp-service #699)

프로젝트 회원의 SNS 가입이 **이제 실제로 동작한다.** 이전에는 프로젝트 도메인에서 소셜
로그인을 해도 통합회원(콘솔 계정)으로 로그인되어 앱이 회원을 인식하지 못했다. 같은 소셜
계정으로 통합회원과 프로젝트 회원이 공존할 수 있게 되면서 해결됐다.

그에 따라 두 가지가 달라졌다:

1. **시작 URL이 절대 경로가 된다.** OAuth 는 provider 콘솔에 등록된 redirect_uri 로만
   돌아올 수 있어 시작점을 콘솔 호스트 하나로 모아야 한다. 프로젝트 앱 도메인에는 `/auth/*`
   경로 자체가 백엔드로 가지 않는다.
2. **가입 후 앱으로 바로 복귀한다.** 예전에는 mBaaS 콘솔 약관 페이지를 거쳤는데, 그 화면은
   통합회원 세션만 읽어 프로젝트 회원은 에러가 났다. 이제 서버는 앱으로 돌려보내기만 한다.

### SDK 표면 (추가만 — 제거·의미 변경 없음)

| 항목 | 변경 |
|---|---|
| `SnsProvider.project_login_url` | 신규 — 프로젝트 회원용 절대 URL. `null` 이면 렌더 금지 |
| `SnsProvider.login_url` | 유지(레거시 소비자용 상대 경로). **생성 앱은 쓰지 않는다** |
| `completeProfile(input)` | 신규 — SNS 복귀 후 약관 동의 + 이름/연락처 저장 |

## 앱에서 무엇을 하면 되나

### SNS 버튼이 없으면
아무것도 안 해도 된다. **재빌드 불필요** — SDK 는 CDN 채널로 자동 반영된다.

### SNS 버튼이 있으면 (2가지)

**① 이동 경로를 바꾼다**

```diff
- window.location.href = provider.login_url;
+ if (!provider.project_login_url) return;   // 렌더하지 않는다
+ window.location.href = provider.project_login_url;
```

문자열을 **가공하지 않는다** — 앞에 호스트를 붙이거나 상대 경로로 되돌리면 깨진다.

**② 복귀 화면을 새로 만든다 (필수)**

SNS 는 provider 화면에서 계정이 만들어져 돌아오므로 가입 폼에 약관과 이름·연락처를 받을
자리가 없다. 앱이 자기 디자인으로 제공해야 한다.

```tsx
const { user } = BaasSDK.useAuth();
if (user && !user.is_profile_completed) {
  const terms = await BaasSDK.getSignupTerms();   // 이메일 가입과 같은 본문
  // → 약관 필수 체크 + 이름/연락처 입력 화면
  await BaasSDK.completeProfile({
    name, phone,               // 010-1234-5678 (하이픈 필수)
    terms_agreed: true,
    privacy_agreed: true,      // 둘 다 true 여야 서버가 통과시킨다
  });
}
```

- `is_profile_completed` 가 false 인 동안은 앱 본 기능으로 넘기지 않는다
- 이미 완료된 회원이 재호출하면 400 `ALREADY_COMPLETED` — 재진입 시 화면을 건너뛴다
- 복귀 지점을 지정하려면 `project_login_url` 에 `&next=/경로` 를 이어 붙인다

## 검증

- SNS 버튼 클릭 → provider 화면 → 앱으로 복귀하는지(콘솔 화면이 뜨면 `login_url` 을 쓰고 있다)
- 복귀 후 약관·추가정보 화면이 뜨고, 저장하면 `is_profile_completed` 가 true 가 되는지
- 약관 체크 전 완료 버튼이 비활성인지
- 하이픈 없는 전화번호를 넣었을 때 400 안내가 보이는지
- `project_login_url` 이 없는 환경에서 버튼이 숨는지
