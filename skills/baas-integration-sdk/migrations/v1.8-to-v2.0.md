# v1.8.0 → v2.0.0 마이그레이션 (고정 기능 제거)

**고정 기능 훅이 SDK 에서 빠졌다.** 게시판·공지/FAQ·댓글·설문·예약·스토어·문의·발송대상은 이제 동적
컬렉션과 serverFn(`baas-backend`)으로 만든다. 회원 인증·파일 업로드·결제 위젯·동적 컬렉션은 그대로다.

## 무엇이 바뀌었나

| 위치 | 전 | 후 |
|---|---|---|
| 훅 | `useBoard` `useNotice` `useFaq` `useComments` `useSurvey` `useReservation` `useStore` `useInquiry` `useRecipient` | 없음 |
| core 함수 | `listPosts` · `createBooking` · `prepareOrder` · `submitInquiry` · `registerRecipient` 등 | 없음 |
| 결제 | 스토어·예약의 `beginWidgetCheckout` + 커스텀 `usePayment().beginWidget` | `usePayment().beginWidget`(serverFn 세션) 하나 |
| 업로드 분류 | `images` `store` `reservation` `board_import` `board_attachment` | `images` |
| 서버 SDK | `sdk.reservation` · `sdk.board` | 없음 |

## 왜 Tier 3 인가

고정 기능을 쓰던 화면은 데이터 출처가 바뀐다(네이티브 테이블 → 프로젝트 컬렉션). 이름 치환으로는 옮길 수
없고, 기존 데이터 이관(서버 일괄 작업)과 화면 재생성이 함께 필요하다. 사용자 동의 후 진행한다.

## 판정

`baas-manifest.json` 의 `features_used` 에 `recipient`·`inquiry`·`notice`·`board`·`survey`·`reservation`·`store`
중 하나라도 있으면 이 앱은 v1 채널에 남겨 두고 이관 대상으로 분류한다. 없으면 v2 로 그대로 올라간다.
