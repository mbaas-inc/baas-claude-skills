# v1.6.1 → v1.6.2 마이그레이션

**서버에 닿지 못한 실패가 한국어 `BaasError` 로 온다.** 지금까지는 오프라인 · 연결 끊김 때 브라우저의
`TypeError("Failed to fetch")` 가 그대로 던져져, `.message` 를 그대로 보여 주라는 안내를 따른 앱 화면에
영문 「Failed to fetch」 가 나왔다(미용실 예약 E2E, 2026-10-05).

## 무엇이 바뀌었나

| 위치 | 전 | 후 |
|---|---|---|
| 모든 SDK 요청(`request`) | 연결 실패 시 `TypeError` 그대로 | `BaasError("서버에 연결하지 못했어요. …", "NETWORK_ERROR", 0)` |
| `uploadFile` · `useFileUpload` 의 S3 PUT | 연결 실패 `TypeError`, 거절 시 `Error("파일 업로드(S3 PUT) 실패: HTTP …")` | 연결 실패 `NETWORK_ERROR`(0), 거절 `BaasError("파일을 올리지 못했어요. …", "UPLOAD_FAILED", <S3 상태>)` |
| `reference/sdk-surface.md` 에러코드 표 | — | `NETWORK_ERROR` · `UPLOAD_FAILED` 행 |
| `reference/sdk-surface.md` 필터 DSL | 연산자 목록만 | 필드 타입별 허용 연산자 표, `like` 는 부분 일치(`%` 를 넣지 않음), 날짜 범위 필드는 `date` 로 |
| `reference/sdk-surface.md` 파일 업로드 | — | 사장님도 앱 안에서는 회원으로 올린다(401 이면 회원 로그인 안내) |

## 무엇이 바뀌지 않았나

- 성공 응답과 서버가 돌려준 실패(`.message` · `.errorCode` · `.status`)는 그대로다.
- 훅은 지금처럼 throw 하지 않고 `error` state 에 담는다 — 담기는 값이 영문 `TypeError` 에서 `BaasError` 로 바뀔 뿐이다.

## 적용 절차

- **앱**: 조치할 것이 없다. `.message` 를 그대로 보여 주던 화면은 자동으로 한국어 안내가 된다.
  `e instanceof TypeError` 로 연결 실패를 따로 잡던 코드가 있다면 `e.errorCode === "NETWORK_ERROR"` 로 바꾼다.
