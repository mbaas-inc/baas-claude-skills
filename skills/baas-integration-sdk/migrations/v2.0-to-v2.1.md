# v2.0.0 → v2.1.0 마이그레이션 (앱 안 관리 화면 제거 · 관리 화면 명세)

**SDK 런타임은 그대로다**(`sdk/package.json` 2.0.0 — CDN 무변경). 바뀐 것은 생성 지침이다. 사장님 운영 화면은
이제 앱이 아니라 AI Studio 관리 화면이 `backend/admin.json` 명세로 그린다.

## 무엇이 바뀌었나

| 위치 | 전 | 후 |
|---|---|---|
| 사장님 화면 | 앱 안 `/admin` 라우트 · 관리자 셸 · 사장님 모드 배지 · `enter-app` 로그인 링크 | 없음 — `backend/admin.json` + `access:'owner'` serverFn |
| 인증 | 관리자 화면은 `RequireAuth` 예외 | 예외 없음(앱에 사장님 화면이 없다). 위임 운영자 화면만 셸 분리 |
| 공지·FAQ | 쓰기 `access:'owner'` serverFn + 앱 작성 화면 | 관리 화면이 직접 쓴다(`owner_content`), 앱은 공개 조회만. 본문은 마크다운 |
| 문의 | 목록 `access:'owner'` serverFn + 앱 목록 화면 | 관리 화면 상세 `thread` + `adminReply`·`adminClose` |
| 본문 렌더 | (게시판 지침) HTML 본문을 그대로 넣기 | 「마크다운 본문 렌더」 — 원본 HTML·`dangerouslySetInnerHTML` 금지 |
| 업로드 분류 | 지침에 `images`·`store`·`reservation` | `images` 하나(코드와 일치) |
| 골격 | — | `extract.mjs` 가 `backend/admin.json` 을 검사(모양·칸·owner 함수·service 직접 쓰기) |

## 왜 Tier 2 인가

배포된 앱은 그대로 동작한다(SDK 무변경). 다만 앱 안 `/admin` 화면을 가진 프로젝트는 관리 화면으로 옮기려면
그 화면을 지우고 `admin.json` 을 써야 해서 화면별 판단이 든다. 기계적 치환이 아니다.

## 판정

`features_used` 에 `account`(관리자 화면 인증 예외)·`collection`(공지·문의)·`storage`(사장님 업로드)가 있으면
대상이다. 프로젝트에 `src/admin/` 이나 `/admin` 라우트가 있을 때만 실제로 고칠 것이 생긴다.

## 어떻게

1. `src/admin/`·`/admin` 라우트·관리자 셸·사장님 로그인 링크를 지운다(사용자가 요청할 때만).
2. 그 화면이 하던 일을 `backend/admin.json` 의 페이지·동작으로 옮기고, 상태 변경은 `access:'owner'` serverFn 으로 둔다.
3. 공지 본문을 앱에서 그리는 곳은 「마크다운 본문 렌더」로 바꾼다.
4. `node backend/extract.mjs` 로 명세 검사를 통과시킨다.
